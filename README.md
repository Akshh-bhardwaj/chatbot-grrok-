# Groq-Powered Chatbot UI

A clean, responsive frontend user interface designed to interact with a backend AI service (like Groq API).

## Features
- **Modern UI**: Clean message bubbles with a fixed input area.
- **Responsive**: Adapts to different screen sizes.

## Structure
- `chatbot.html`: The main user interface for the chatbot.
